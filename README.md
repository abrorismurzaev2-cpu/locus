## Осталось 2 шага (1 минута)

### 1. Залить полный `index.html`

Файл `locus.html` у тебя уже есть (скачай из чата / artifacts).

1. Открой: https://github.com/abrorismurzaev2-cpu/locus
2. Нажми **Add file → Upload files**
3. Перетащи **`locus.html`**, переименуй в **`index.html`** (замени старый)
4. Commit changes

### 2. Включить GitHub Pages

1. https://github.com/abrorismurzaev2-cpu/locus/settings/pages
2. **Source:** Deploy from a branch
3. **Branch:** `main` → `/ (root)` → **Save**

Через 1–2 минуты открой:

**https://abrorismurzaev2-cpu.github.io/locus/**

Только в **Chrome или Edge** (нужен WebGPU).
